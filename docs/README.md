# Documentation map

Use this page to find the current guidance and distinguish it from design history.

Current API behavior belongs in the code and current API references. Proposals are not available APIs; ADRs record why durable choices were made, and research notes record evidence that may inform future choices.

| --- | --- |

| [`../ARCHITECTURE.md`](../ARCHITECTURE.md) | Current workspace structure and data flow. |

| [`projects/`](projects/) | Project plans and records. Check status and superseded notices before treating them as active. |
